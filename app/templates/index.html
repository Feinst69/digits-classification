Comment le réseau "voit" votre chiffre

Voici les cartes de caractéristiques (feature maps) des couches convolutionnelles. Chaque filtre détecte des motifs spécifiques comme les contours, les courbes ou les textures.

🔍

Les filtres CNN apparaîtront ici après une prédiction

Comprendre les visualisations :

Activation : Mesure l'intensité de réponse du filtre aux motifs détectés dans votre chiffre. Plus la valeur est élevée, plus le filtre "reconnaît" des caractéristiques importantes.

Bloc de Convolution : Chaque bloc analyse l'image à un niveau différent - le 1er détecte des contours simples, le 2e reconnaît des formes plus complexes qui permettent d'identifier le chiffre.

Les zones claires dans les filtres montrent où le réseau "porte son attention" pour reconnaître votre chiffre.

Comment ça marche ?

Deux options s'offrent à vous pour tester le modèle de reconnaissance de chiffres :

  1. Dessinez un chiffre dans la zone de dessin ci-dessus - la prédiction se fait automatiquement quand vous arrêtez de dessiner
  2. Ou glissez-déposez une image de chiffre manuscrit pour une analyse instantanée

Les résultats s'affichent automatiquement en temps réel sur cette page, sans besoin de cliquer sur un bouton !

Nouveau : Activez l'option "Afficher les filtres CNN" pour voir comment le réseau neuronal analyse votre chiffre couche par couche.
